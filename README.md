# Monster Framework

A server extension for Rust (Oxide and Carbon) that monster and boss plugins are built on.

## Getting it

Add `MonsterFrameworkUpdater.cs` to your plugins folder. On server start it downloads `Oxide.Ext.MonsterFramework.dll` into the extensions folder if it is missing, replaces it when a newer release is out, and tells you in the console to restart.

The DLL itself is on the [Releases](https://github.com/RickySpanish343/MonsterFramework/releases) page.
